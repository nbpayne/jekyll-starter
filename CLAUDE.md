## Commands

**Install dependencies (first time):**
```sh
bundle install   # Jekyll and Ruby gems
yarn             # Node/Gulp dev tools + client-side deps (Bootstrap, jQuery)
```

**Development (build + serve + watch):**
```sh
gulp             # Full build, start Jekyll with livereload, watch for changes
```

**Build + serve (no file watching):**
```sh
gulp build
```

**Watch CSS/JS only (Jekyll already running):**
```sh
gulp liveReload
```

Site is served at `http://127.0.0.1:4000` with `--livereload`, `--drafts`, and `--future` flags.

## Build pipeline

The Gulp pipeline runs in this order:

1. **`clean`** — deletes `css/**/*` and `js/**/*`
2. **`css`** — compiles `__sass/**/*.scss` → `css/` (unminified + `.min.css` with sourcemap)
3. **`lintJS`** — ESLints `__js/**/*.js`
4. **`js`** — bundles `node_modules/jquery` → `js/vendor.min.js`, `node_modules/bootstrap` → `js/bootstrap.min.js`, `__js/**/*.js` → `js/app.min.js` (all uglified with sourcemaps)
5. **`jekyllServe`** — spawns `jekyll serve`

`gulp liveReload` watches `__sass/` and `__js/` and re-runs the relevant tasks on change.

### Source vs. output directories

| Write here | Gets built to |
|---|---|
| `__sass/` | `css/` |
| `__js/` | `js/app.min.js` |
| `node_modules/jquery` | `js/vendor.min.js` |
| `node_modules/bootstrap` | `js/bootstrap.min.js` |

Never edit files in `css/` or `js/` directly — they are regenerated on every build.

## Jekyll structure

- `_layouts/` — page layouts (Liquid templates)
- `_includes/` — partials included by layouts; `head.html` and `foot.html` are hand-authored (no longer generated by Gulp)
- `_config.yml` — site config; requires Jekyll restart to take effect
- `_site/` — Jekyll build output; not committed
- Content pages are Markdown files at the repo root (`index.md`, `about.md`, etc.)

## JS dependencies

Bootstrap and jQuery are installed as Yarn dependencies (`package.json`) and bundled directly from `node_modules` by the `js` Gulp task. There is no Bower step.

## ESLint

Config is in `eslint.config.js` (flat config format). Rules enforce: 2-space indent, single quotes, semicolons, `===`, curly braces required, trailing commas in multiline. Linting runs automatically as part of the Gulp build and will fail the build on errors.
